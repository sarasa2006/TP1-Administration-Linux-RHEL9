# TP1 - Introduction à l'administration Linux RHEL 9

**Module :** Administration Unix  
**Niveau :** 4IIR  
**Année universitaire :** 2026/2027

## Objectifs
- Découvrir Red Hat Enterprise Linux 9.
- Maîtriser les commandes Linux de base.
- Explorer le système de fichiers FHS.
- Utiliser le terminal Bash et les redirections.
- Configurer et tester une connexion SSH.

## Parties réalisées
1. Installation de RHEL 9.
2. Commandes de base Linux.
3. Découverte du FHS.
4. Terminal et aide en ligne.
5. Redirections, pipes et filtres.
6. Accès distant sécurisé avec SSH.

## Vérification SSH
- Serveur : localhost.localdomain
- Utilisateur : emsi
- Adresse IP : 192.168.15.128
- Port : 22
- Connexion distante : réussie.
- Exécution distante : réussie.
